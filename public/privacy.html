Sirenes

Privacy Policy

Effective 5 September 2026. Applies to the Sirenes web application at sirenes.vivedo.me.

Sirenes is a browser application for editing Mermaid diagrams. It has no server of its own. Everything you do happens in your browser, and the only remote services it contacts are the ones you choose to use: Google Drive, OpenRouter, and, for live sessions, a connection broker. This page lists exactly what data is involved, where it goes, and how to remove it.

Who is responsible

Sirenes is operated by vivedo, Italy. For any question about this policy or your data, write to privacy@vivedo.me.

Data that stays in your browser

The following is stored only on your device, in the browser's storage for this site. It is never sent to us. You can delete all of it at any time with Privacy → Clear all data inside the app, or by clearing site data in your browser.

  • Your diagrams, including autosaved drafts, and which diagram you last worked on.
  • Interface preferences: theme, layout, panel sizes.
  • Your OpenRouter API key, if you enter one, kept in localStorage or for the current session as you choose.
  • AI conversation history, kept per diagram.
  • References to local files you opened, so the app can save back to them.
  • A list of recently opened files.

Data that leaves your browser, and to whom

When What is sent To whom
You open a share link, or copy one The full diagram, compressed, is part of the link itself. Anyone with the link can read it. Links may be kept in browser history and in whatever tool you paste them into. Whoever you send the link to. Our web host receives only the page request, not the diagram: it travels in the URL fragment, which browsers do not send to servers.
You use the AI assistant Your API key, the current diagram, your prompts, and recent conversation turns. OpenRouter (openrouter.ai), which forwards the request to the model provider you selected. Their handling is governed by OpenRouter's privacy policy.
You sign in to Google and open or save a file on Drive A sign-in request, then only the files you pick or create with Sirenes. Google (accounts.google.com, www.googleapis.com). Sirenes requests the drive.file scope only, which limits its access to files you explicitly choose or create with it. It cannot list or read the rest of your Drive.
You start or join a live session Connection set-up data (peer identifiers and network candidates) goes to the signalling server. The diagram, your cursor position, your display name, and, if the host allows it, AI prompts and replies travel directly between participants over an encrypted WebRTC channel. The signalling server (by default the public PeerJS server, 0.peerjs.com) sees connection metadata only, never diagram content. The other participants see the shared file and presence information.

Google user data

Sirenes accesses Google Drive only to open files you select through the Google file picker and to create or update files you save through Sirenes. It reads and writes the content of those files and their names. It does not access other files, folders, or account information beyond what Google's sign-in returns for the picker to work.

The Google access token is held in memory for the duration of the page and is never written to storage. Signing out within the app revokes it. Sirenes does not transfer Google user data to any third party, does not use it for advertising, and does not use it to train machine-learning models. Use of Google user data complies with the Google API Services User Data Policy, including its Limited Use requirements.

What we do not do

  • No analytics, tracking pixels, or advertising.
  • No cookies set by Sirenes.
  • No account, no sign-up, no server-side storage of your content.
  • No third-party scripts other than Google's sign-in and file picker libraries, loaded only when you use Drive.

Hosting

The application files are served by GitHub Pages. Like any web host, GitHub records standard request logs (IP address, user agent, requested path). Diagram content is not part of those requests. See GitHub's privacy statement.

Your rights and how to exercise them

Because we hold no data about you on our systems, deletion is entirely in your hands: use Clear all data in the app, revoke Sirenes in your Google account permissions, and manage your OpenRouter key at openrouter.ai. If you believe we hold anything about you, or have any concern, contact privacy@vivedo.me and we will respond within 30 days.

Changes

If this policy changes, the new version is published at this address with a new effective date. Changes that affect how Google user data is handled will be reflected in the app's Google verification as required.
